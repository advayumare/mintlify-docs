# ThreadCRM — Release Notes v1.5.0

**Release Date:** October 1, 2026  
**Previous Version:** v1.4.0  
**Codename:** Connected Workflows

## 🚀 Highlights

ThreadCRM v1.5.0 expands the platform's communication and automation capabilities while strengthening subscription management and CRM controls.

This release introduces a new **WhatsApp Inbox**, improves **workflow-based email sending**, adds event triggers for automated workflows, enhances **lead and deal plan enforcement**, and brings several improvements to **AI, reporting, dashboards, billing, and user management**.

---

## ✨ New Features

### 1. WhatsApp Inbox

ThreadCRM now includes a dedicated **WhatsApp Inbox** experience.

**What's new:**

- Added the WhatsApp Inbox module.
- Integrated the WhatsApp messaging module into the CRM.
- Provides a dedicated foundation for managing WhatsApp conversations from within ThreadCRM.

**Why it matters:**  
Teams can bring WhatsApp conversations into their CRM workspace and manage customer communication alongside their existing CRM activities.

---

### 2. Workflow Email Sending with Gmail

Workflow automation now supports sending emails through Gmail.

**What's new:**

- Added Gmail-based email sending for workflows.
- Workflow-sent emails are now maintained in the CRM's email tab.
- Improved synchronization between workflow email activity and the email experience.

**Why it matters:**  
Automated emails sent through workflows can now remain visible within the CRM, providing better continuity between automation and manual communication.

---

### 3. Event Triggers for Lead Creation & Updates

Workflow automation receives new event-based trigger support.

**What's new:**

- Added event handling for DAG triggers.
- Added events for **lead creation**.
- Added events for **lead updates**.

**Why it matters:**  
CRM changes can now serve as automation triggers, creating a foundation for more event-driven workflows.

---

### 4. Enhanced Lead & Deal Stage Management

Lead and user stage management has been updated.

**What's new:**

- Updated lead stage handling.
- Updated user stage functionality.
- Added support for hiding lead stages where applicable.
- Improved stage-related CRM behavior.

---

### 5. Subscription & Plan Limit Improvements

Subscription management receives several important improvements.

**What's new:**

- Purchased plan limits can now be frozen so later catalog changes apply only to new buyers.
- Lead and Deal plan limits are enforced during conversion.
- Campaign add-ons are now mapped to campaign limits rather than People limits.
- Licensed seats are constrained by the purchased seat count.
- Current-period usage is considered when calculating licensed seats.
- Purchased AI credits and shared add-on usage are reflected in billing.
- AI credit packs are streamlined in the feature catalog.    

**Why it matters:**  
Existing customers can retain the limits associated with their purchased plans while new plan configurations can evolve independently.

---

### 6. Improved Billing & Invoices

Billing information is now more transparent.

**What's new:**

- Invoices now show:
    - Plan fees
    - Add-on prices
    - GST
- Tax calculations use the tax rate selected when the plan was created.

**Why it matters:**  
Customers and administrators get clearer visibility into subscription charges and applicable taxes.

---

**What's new:**

**Why it matters:**

ThreadCRM's AI packaging has been redesigned to simplify AI add-ons.

**What's new:**

    - **AI Starter**

The new structure provides a clearer way to package AI capabilities and gives customers a more straightforward path to scale their AI usage.

Add-on usage management has been enhanced to provide more accurate subscription-period tracking.

- Improved preservation of email integration limits during plan updates.

**Why it matters:**  
Administrators can configure subscription plans more precisely while keeping customer-facing plan comparisons focused on relevant capabilities.

---

### 6. Super Admin Auto-Pay Configuration

Super Admin subscription administration now includes an API for auto-payment configuration.

**What's new:**

- Added Super Admin auto-pay configuration API.
- Improved subscription administration capabilities.

---

### 7. License Removal & User Access Control

User licensing behavior has been strengthened.

**What's new:**

- Users are automatically logged out when an administrator removes their license.
- Improved license enforcement across active sessions.

**Why it matters:**  
Removing a user's license now takes effect immediately for their active session, helping ensure subscription and access controls remain synchronized.

### 8. Custom Dashboard Improvements

Custom Dashboards receive additional backend and export improvements.

**What's new:**

- Improved Custom Dashboard widget UX.

Thread CRM v1.0.0 is the first production release of the platform — a multi-tenant sales and marketing CRM built on a two-layer backend architecture: the Core Engine (platform services) and Business Modules (CRM features). ## Highlights

- Multi-tenant workspaces with isolated data, role-based access, and team collaboration
- Full CRM core — leads, contacts, companies, deals, tasks, notes, and activity timelines
- Multi-channel outbound — email, LinkedIn, WhatsApp, and AI voice call sequences
- Built-in AI — record-level copilot, template generation, and workflow AI agents
- Automation engine — visual workflows with triggers, branching, delays, and HTTP/code actions
- Developer-ready — OAuth API, workspace API keys, outbound webhooks, and connected apps

## Platform Foundation (Core Engine)

The Core Engine powers identity, tenancy, and shared infrastructure for every workspace.

### Identity & Access

- Email/password sign-up and sign-in with JWT sessions (access + refresh tokens)
- Social login via Google and Microsoft OAuth (PKCE)
- Optional email OTP verification and password reset flows
- Invite-link signup that can bypass OTP when the invite proves mailbox access
- Multi-workspace membership — users can belong to and switch between workspaces

### Workspace & Team

- Workspace activation with isolated database provisioning per tenant
- Custom workspace name, domain, subdomain, and logo branding
- Team invitations by email or public invite link, with role assignment
- Guided onboarding flow (profile setup, team invite, completion tracking)
- Default role configuration for new members

### Files & Storage

- Secure file uploads and downloads scoped to workspace
- Attachments on CRM records, profile pictures, and workspace logos
- Pluggable storage: local filesystem or S3-compatible object storage (AWS / MinIO)
- Optional auto-sync to Google Drive and OneDrive under organized folder paths

### Email Infrastructure

- Asynchronous email delivery with retry via background job queue
- Send via workspace SMTP settings or OAuth-connected Outlook accounts
- Transactional email for invites, OTP verification, and password reset

### Integrations & Admin

- OAuth 2.0 API for third-party apps with scoped access to contacts, companies, leads, and deals
- Platform Admin Panel for super-admins: workspace search, user management, and platform stats
- Impersonation for authorized support sessions with audit-friendly token claims
- Domain manager for workspace URL generation (subdomain + custom domain support)

### AI & Reliability

- Streaming AI chat endpoint with multi-provider support (OpenAI, Anthropic, xAI)
- Per-workspace AI usage and cost tracking
- Background job processing (sync, PostgreSQL pg-boss, or Redis BullMQ)
- Global exception handling with optional Sentry reporting
- Health check endpoint (`/healthz`) for load balancers and deploy verification
- Redis-backed session storage for production

## Architecture Notes

- Two-layer design: `CoreEngineModule` (21 platform modules) + `ModulesModule` (40+ feature modules)
- Multi-tenant isolation: each workspace gets its own data store
- Queue-driven async work: email, imports, campaigns, workflows, and webhooks run in background jobs
- Pluggable drivers: file storage (local/S3), message queue (sync/pg-boss/BullMQ), logging, and exception handling

## Known Limitations (v1.0.0)

- Opportunity module exists as a data model only — Deals is the active sales pipeline
- Two email surfaces: Messaging (CRM-logged threads on records) vs. Workspace Email (full personal inbox)
